# Acert

API that enables the generation of certificates from an SVG file.

## 💻 Pre-Requisites

- Node v18 or higher
- Docker 27.0.3 or higher

## 🚀 Installation

1. Clone this repo

2. Install the dependencies using your preferred node package manager 

```
    npm i
```

3. Create a `.env` file using the same structure as `.env-example`

4. Run the project using Docker compose

```
    docker compose up --build
```
